## 📖 项目简介

**MindGraph** 是一款 **AI 原生的个人知识管理系统（PKM）**，专为希望高效管理碎片化知识的人设计。它融合了 Obsidian 的双向链接理念、Notion 的 AI 能力与可视化知识图谱，并以**本地优先、零配置、开箱即用**的体验呈现。

核心工作流：**书写 → 自动关联 → 图谱探索 → AI 辅助整理**

你只需专注于书写，MindGraph 自动帮你：

- 通过 `[[双向链接]]` 串联笔记，构建知识网络
- 通过 `#标签` 自动归类，AI 还能智能推荐标签
- 通过**交互式知识图谱**俯瞰全局知识结构
- 借助 **DeepSeek AI** 一键生成摘要、推荐标签、自动生成标题

### 🎯 与主流工具的对比

|---|---|---|---|---|
| 数据所有权 | ✅ 本地文件 | ❌ 云端 | ✅ 本地文件 | ✅ **本地 SQLite** |
| AI 能力 | 需插件 | ✅ 付费 | 需插件 | ✅ **内置 DeepSeek** |
| 双向链接 | ✅ | ✅ | ✅ | ✅ |

| 上手难度 | 需配置插件 | 需注册 | 需学习大纲 | ✅ **双击即用** |
| AI 标签推荐 | ❌ | ❌ | ❌ | ✅ |
| AI 摘要生成 | ❌ | ❌ | ❌ | ✅ |
| 桌面应用 | ✅ Electron | ✅ Electron | ✅ Electron | ✅ **Electron + 便携版** |

## 💡 创作缘由

在日常学习和工作中，我发现自己面临着几个普遍的痛点：

### 1. 知识碎片化严重

每天接触大量信息——技术文章、读书笔记、项目心得、会议记录——它们散落在各种地方：浏览器书签、本地 Markdown 文件、备忘录、聊天记录。当我想回顾某个知识点时，常常找不到或者忘了它和哪些其他知识相关。

### 2. 现有工具的痛点

- **Obsidian**：功能强大但需要折腾插件和配置，对新手不友好；图谱功能只读，缺乏交互性；AI 能力需要付费或复杂配置。
- **Notion**：数据在云端，隐私担忧；离线体验差；功能臃肿，启动慢。
- **Logseq**：大纲式编辑学习成本高，不符合大多数人的写作习惯。

### 3. 知识之间缺乏"链接"

传统的笔记工具是孤立的文档集合，但人类的知识本质上是**网络状的**——一个概念连接另一个概念，一个想法引发另一个想法。我需要一个工具，能自然地表达这种关联，并用可视化的方式展现出来。

### 4. AI 时代的机遇

2024-2025 年，大语言模型（LLM）变得触手可及。DeepSeek 提供了高质量且价格亲民的 API。我想：为什么不把 AI 直接嵌入知识管理工具中，让它帮我做那些繁琐的整理工作——归类标签、总结要点、生成标题？

> **于是我决定自己动手，打造一个真正符合自己需求的知识管理工具。**

## 🌟 创作灵感

MindGraph 的诞生受到了以下几个来源的深刻启发：

### 1. Obsidian 的本地优先哲学

Obsidian 证明了**本地 Markdown 文件 + 双向链接**是一种强大且可持续的知识管理范式。数据归你所有，不依赖任何云服务，这让我坚定了**本地优先**的设计原则。MindGraph 使用本地 SQLite 数据库存储数据，不依赖任何外部服务。

### 2. Roam Research 的网络化思维

Roam Research 提出了"网络化笔记"的概念——每一则笔记都是一个节点，链接让它们形成网络，而不是层级树。这种思考方式比传统的文件夹分类更符合人脑的工作方式。MindGraph 的双向链接和知识图谱正是对这种理念的实现。

### 3. D3.js 的交互式可视化

大多数笔记工具的知识图谱都是只读的——你只能看，不能动。D3.js 的力导向图启发了我：为什么不能像操作地图一样，**拖拽、缩放、探索**你的知识结构？MindGraph 的图谱支持完全交互式操作。

### 4. VS Code 的编辑器美学

VS Code 的暗色主题、等宽字体、简洁布局一直是开发者社区的设计标杆。MindGraph 的 UI 设计大量参考了 VS Code 的配色方案和布局哲学，使用了紫色作为强调色，打造一个让开发者感到亲切的写作环境。

### 5. AI Copilot 的辅助理念

GitHub Copilot 证明了 AI 不应该替代人类创作，而是作为**副驾驶**辅助人类。MindGraph 的 AI 功能遵循同样的理念：AI 推荐标签，但由你决定是否采纳；AI 生成摘要，但由你判断是否准确。**AI 是助手，不是替代者。**

## ✨ 核心特性

### 🔗 双向链接 — 知识网络的基础

使用 `[[笔记标题]]` 语法创建链接，MindGraph 自动处理一切：

- ✅ 自动从当前笔记创建到目标笔记的**出向链接**
- ✅ 在目标笔记显示**反向链接**（谁链接到了我）
- ✅ 链接关系自动汇入**知识图谱**
- ✅ 链接目标不存在时，自动创建**存根笔记**，后续可以填充内容
- ✅ 编辑器中 **Wiki 链接语法高亮**，可点击跳转
- ✅ 悬停 Wiki 链接时显示**笔记预览卡片**

### 🕸️ 交互式知识图谱 — 俯瞰知识全景

点击「图谱」按钮，打开全屏交互式可视化：

- 🖱️ **拖拽节点**自由排列，探索知识结构
- 🔍 **滚轮缩放**，从全局到细节
- 👆 **双击节点**直接打开对应笔记
- 📏 节点大小反映**连接数量**（越重要的笔记越大）
- 🎨 节点颜色按连接数渐变（灰 → 紫 → 深紫）
- 🔄 支持**适应窗口**一键还原最佳视图

### 🤖 AI 智能助手 — 你的知识副驾驶

基于 **DeepSeek API**，在编辑器工具栏一键调用：

| 功能 | 说明 | 使用场景 |
|------|------|----------|
| 🏷️ **推荐标签** | AI 分析笔记内容，推荐 3-5 个精准标签，点击即可添加 | 写完笔记后快速归类 |
| 📝 **生成摘要** | AI 自动提取核心要点，2-3 句话概括 | 回顾长篇笔记时快速了解内容 |
| 💡 **生成标题** | AI 根据内容自动生成简洁标题 | 灵感草稿快速定题 |

> 💰 **成本极低**：DeepSeek API 价格约为 GPT-4 的 1/50，日常使用几乎免费。

### 🖼️ 图片粘贴 — Ctrl+V 即可

不需要手动上传、不需要配置图床：

- 在编辑器中直接 `Ctrl+V` 粘贴剪贴板中的图片
- 自动上传到本地 `data/images/` 目录存储
- 自动插入标准 Markdown 图片语法 `![pasted-image](/data/images/xxx.png)`
- 阅读模式支持**点击放大**（medium-zoom）

### 📝 智能编辑器 — 所见即所得体验

定制开发的混合编辑器，兼顾编辑体验和 Markdown 纯文本优势：

- **语法高亮层**：标题、粗体、斜体、代码、Wiki 链接等实时高亮
- **透明光标层**：保留原生 textarea 的编辑能力
- **IME 兼容**：完美支持中文输入法
- **阅读模式**：一键切换 Markdown 渲染视图，代码高亮、图片缩放一应俱全
- **自动保存**：1.5 秒防抖自动保存，再也不怕丢失内容

### 🏷️ 智能标签系统

- 内容中使用 `#标签名` 语法自动提取
- 侧边栏显示所有标签及对应笔记数量
- 点击标签一键筛选相关笔记
- AI 可以**分析内容并推荐标签**，点击即添加到笔记中

### 📅 每日日记

- 一键创建当天日记，自动以日期命名
- 适合每日记录、会议笔记、个人反思
- 日记与普通笔记通过双向链接无缝关联

### 🌓 暗色/亮色主题

- 基于 VS Code 暗色主题（#1e1e1e 底色 + 紫色强调）
- 点击顶栏 ☀️/🌙 按钮一键切换
- 主题偏好自动保存在 localStorage 中
- 所有 UI 组件均有明暗双套 CSS 变量

### 📥 Markdown 导出

- 支持将任意笔记导出为标准 Markdown 文件（含 YAML frontmatter）
- 标签、创建时间等元数据一并导出
- 可配合其他 Markdown 工具使用

### 🖥️ 跨平台桌面应用

- 基于 **Electron** 打包为原生桌面应用
- 支持 **Windows**（NSIS 安装包 / Portable 便携版）
- 支持 **macOS**（DMG / Zip）
- 支持 **Linux**（AppImage / deb）
- 原生应用菜单栏、键盘快捷键
- 窗口尺寸记忆、安全沙箱隔离

| 层级 | 技术 | 选择理由 |
|------|------|----------|
| **运行时** | Node.js 18+ | ESM 模块、`--env-file` 原生支持、广泛的生态 |

| **AI 服务** | **DeepSeek API** | 国产大模型、中文理解能力强、OpenAI 兼容协议、**成本极低** |
| **桌面框架** | **Electron 33.x** | 跨平台桌面应用、Chromium 渲染引擎、成熟稳定的生态 |
| **打包工具** | **electron-builder** | 支持 NSIS/Portable/DMG/AppImage 多格式打包 |

### 关键技术决策

#### 1. 为什么用 sql.js 而不是 better-sqlite3？

`better-sqlite3` 需要编译原生 C++ 模块（node-gyp），这在 Electron 打包时会产生大量兼容性问题（不同 Electron 版本需要重新编译、不同平台的预编译二进制不通用）。`sql.js` 是 SQLite 的 WASM 编译版本，纯 JavaScript 实现，**零原生依赖**，打包到 Electron 后在任何平台都能直接运行。

#### 2. 为什么不用 React/Vue？

MindGraph 是一个**中等复杂度的单页应用**，核心复杂度在于编辑器语法高亮和 D3 图谱交互，这些都需要直接操作 DOM。使用框架会引入额外的抽象层和打包工具链，而原生 JS + ES Modules 在现代浏览器中已足够强大，且能做到**零构建**开发体验。

#### 3. 自定义编辑器 vs CodeMirror/Monaco？

CodeMirror 和 Monaco 虽然功能强大，但它们是"代码编辑器"而非"写作编辑器"。MindGraph 需要的是对 `[[wiki-link]]` 和 `#tag` 的定制高亮，以及透明 textarea + 镜像高亮层的 WYSIWYG 体验。自建编辑器虽然工作量大，但**完全掌控每一像素的渲染**。

## 🚀 快速部署

### 方式一：便携版（推荐 — 零安装）

1. 从 [Releases](https://github.com/ly99LLL/mindgraph/releases) 页面下载 `MindGraph.exe`
2. 双击运行
3. 浏览器自动打开 `http://localhost:3456`
4. 开始写作！

> 数据自动保存在 `MindGraph.exe` 同级目录下的 `data/` 文件夹中。换电脑时，**只需拷贝整个文件夹**即可迁移所有数据。

### 方式二：源码运行（开发者）

```bash
# 1. 克隆项目
git clone https://github.com/ly99LLL/mindgraph.git
cd mindgraph

# 2. 配置 AI（可选 — 不配置也能使用全部基础功能）
cp .env.example .env
# 编辑 .env，填入 DeepSeek API Key（在 https://platform.deepseek.com 获取）

# 3. 安装依赖
npm install

# 4. 启动开发服务器（支持热重载）
npm run dev
# → 浏览器打开 http://localhost:3456
```

### 方式三：Electron 桌面开发

```bash
# 开发模式（带 DevTools）
npm run electron

# 打包 Windows 便携版
npm run build:win

# 打包 macOS
npm run build:mac

# 打包 Linux
npm run build:linux
```

### 方式四：生产部署

```bash
# 服务器模式（无 Electron）
npm start
# → 默认监听 http://localhost:3456
# 支持反向代理（Nginx/Caddy）部署到服务器
```

### 环境变量配置

在项目根目录创建 `.env` 文件：

```env
# DeepSeek API 配置
# 获取 API Key: https://platform.deepseek.com
DEEPSEEK_API_KEY=sk-your-key-here
DEEPSEEK_API_BASE=https://api.deepseek.com/v1/chat/completions
DEEPSEEK_MODEL=deepseek-chat

# 自定义端口（可选，默认 3456）
PORT=3456
```

> ⚠️ 不配置 API Key 不影响基础功能：笔记编辑、双向链接、知识图谱、标签系统、图片管理等均可正常使用。

## 🌍 项目意义

### 1. 推动"本地优先"的知识管理理念

在 SaaS 盛行的时代，用户的数据越来越多地存储在云端，面临着隐私泄露、服务关停、数据迁移困难等风险。MindGraph 践行**本地优先（Local-First）**原则：

- 数据存储在本地 SQLite 数据库，**你完全拥有自己的数据**
- 无需注册任何账号，**离线也能正常使用**
- 可以随时导出为标准 Markdown 文件，**数据永远不会被锁定**

### 2. 降低个人知识管理的门槛

优秀的 PKM 工具往往有较高的学习曲线——Obsidian 需要配置插件、Logseq 需要适应大纲思维、Notion 需要学习数据库公式……MindGraph 的理念是：**打开就能用，AI 帮你理**。

- 不需要学习复杂的概念
- 不需要配置任何插件
- AI 助手帮你完成标签、摘要等繁琐工作

### 3. 探索 AI + 知识管理的最佳实践

大语言模型在知识管理领域的应用还处于早期阶段。MindGraph 进行了有意义的探索：

- **AI 不替代思考**：AI 推荐标签和摘要，但最终由用户决定
- **AI 增强关联**：通过分析内容语义，AI 可以建议笔记之间的关联
- **成本可控**：使用 DeepSeek 等低成本模型，让 AI 功能真正可用

### 4. 开源社区的贡献

作为一个开源项目，MindGraph 为社区提供了：

- 一个**完整的 Electron + Express + sql.js 架构参考**
- **自定义 Markdown 编辑器**的实现思路（透明 textarea + 语法高亮镜像层）
- **sql.js 在桌面应用中的实践**（零原生依赖打包方案）
- **DeepSeek API 集成**的完整示例
